# System Architecture

> Bu doküman henüz boş bir iskelettir. İçerik Phase 7 (Pyomo implementasyonu), Phase 13-16 (Digital Twin / Simulation / entegrasyon döngüsü) ve Phase 22 (mimari sadeleştirme) ilerledikçe doldurulacaktır.

Üst düzey mimari diyagram ve modül sorumlulukları için şimdilik bkz. [project-plan.md](project-plan.md) Bölüm C.

- Modül sorumlulukları (data_generator, preprocessing, ml, optimization, simulation, digital_twin, backend)
- Veri akışı diyagramı (Factory Data → Digital Twin → ML → Optimization → Simulation → Scenario)
- API endpoint tasarımı
- Ana döngünün (Phase 16) modül bazlı kırılımı
